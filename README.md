# Detecting Exoplanet Transits Using Photometric Light Curve Analysis

## Overview
This project analyzes photometric light curve data to detect potential exoplanet transit events using Python.

## Objectives
- Process astronomical light curve data
- Identify transit signals
- Visualize brightness variations
- Estimate transit parameters

## Tools
- Python
- NumPy
- Pandas
- Matplotlib
- SciPy

## Results
The analysis successfully identified transit-like signatures in photometric observations and demonstrated the effectiveness of light curve analysis for exoplanet detection.
